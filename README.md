- `index.html` — Main landing page + interactive Brand & Advertising Studio
- `style.css` — Responsive dark-gold styling + multi-format ad preview cards
- `script.js` — Product catalog, WhatsApp cart (`919593594429`), and ad creative switcher
- `images/`
  - `logo-emblem.png` — Transparent background emblem (original brown/gold)
  - `logo-emblem-gold.png` — Transparent background emblem (brightened gold for dark themes)
  - `logo-full-transparent.png` — Full transparent logo with `SHIV NOLEN GUR (SNG)` text
  - `logo-full-gold.png` — Full transparent logo optimized for dark backgrounds
  - `hero.jpg`, `product-liquid.jpg`, `product-patali.jpg`, `product-blocks.jpg`, `product-gift.jpg`, `about-1.jpg`

## Deployment
Upload all files and the `images/` folder to GitHub Pages, Netlify, Vercel, or any static host.
